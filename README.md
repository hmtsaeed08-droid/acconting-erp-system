# ERP محاسبي — المرحلة الأولى

هذه الحزمة تحتوي على:
- `apps-script/Code.gs`: إنشاء أوراق Google Sheets، إعداد المدير الأول، تسجيل الدخول، الجلسات، وسلطات المرحلة الأولى.
- `frontend/`: تطبيق React + TypeScript + Vite بواجهة عربية RTL أولية لتسجيل الدخول ومساحة العمل.

## 1) إنشاء قاعدة البيانات
1. أنشئ Google Sheet جديداً من الجوال.
2. افتح قائمة Extensions ثم Apps Script (قد تحتاج عرض سطح المكتب في المتصفح).
3. استبدل محتوى `Code.gs` بالكود الموجود في `apps-script/Code.gs`.
4. احفظ المشروع، واختر الدالة `setup` ثم Run ووافق على الصلاحيات.
5. عند أول تشغيل ستظهر كلمة مرور مؤقتة للمدير `admin`. انسخها واحفظها فوراً؛ لا يمكن عرضها ثانية.

## 2) نشر Apps Script
1. Deploy > New deployment.
2. اختر Web app.
3. Execute as: Me.
4. Who has access: اختر النطاق المناسب. لا تجعل ملف Google Sheet عاماً.
5. Deploy ثم انسخ رابط `/exec`.

## 3) تشغيل React
يتطلب جهازاً عليه Node.js وبيئة تطوير:
1. ادخل مجلد `frontend`.
2. انسخ `.env.example` إلى `.env` وضع رابط `/exec` الحقيقي في `VITE_GAS_WEB_APP_URL`.
3. نفّذ `npm install`.
4. نفّذ `npm run dev` للتجربة أو `npm run build` للبناء.

## 4) تنبيه مهم حول CORS
قد تمنع المتصفحات طلبات `fetch` من Vercel/GitHub Pages إلى Apps Script بسبب إعادة التوجيه وسياسات CORS. هذه الحزمة تستخدم POST بنوع `text/plain` لتقليل طلبات preflight، لكن ذلك لا يضمن السماح بالاتصال من كل متصفح أو نطاق. إذا ظهر خطأ CORS، شغّل الواجهة من HTML Service داخل Apps Script أو استخدم طبقة وسيطة موثوقة؛ لا تستخدم `mode: no-cors` لأنه يمنع قراءة الرد.

## 5) حدود المرحلة الأولى
هذه المرحلة تنشئ المخطط والمصادقة وإدارة المستخدمين الأساسية والواجهة الأولية فقط. وحدات القيود والنقليات والدخل الذكي والتقارير والطباعة والتصدير والنسخ الاحتياطي لم تُنفذ بعد. لا تستخدمها للإنتاج أو لحفظ قيود فعلية.

## الأمان
- لا توجد كلمة مرور ثابتة `admin123`؛ ينشئ setup كلمة مرور عشوائية مؤقتة.
- SHA-256 مع Salt مطبق، لكنه ليس بديلاً عن خوارزمية مخصصة لكلمات المرور مثل Argon2/bcrypt؛ Google Apps Script لا يوفرها أصلياً.
- سجل IP غير متاح بصورة موثوقة عبر Apps Script، لذلك يسجل كـ "غير متاح".
- حماية الوصول إلى الشيت تعتمد أيضاً على إعدادات مشاركة Google Sheet وحساب مالكه.
